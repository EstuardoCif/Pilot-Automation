# Setup from zero — Windows / PowerShell

## 1. Install prerequisites

Install:
- Git for Windows
- Node.js 24 LTS
- GitHub CLI
- Claude Code

Recommended commands where available:

```powershell
winget install --id Git.Git -e
winget install --id GitHub.cli -e
winget install Anthropic.ClaudeCode
```

Install Node.js 24 LTS from the official Node.js installer if it is not already installed.

Restart the terminal, then verify:

```powershell
git --version
node --version
npm --version
gh --version
claude --version
```

## 2. Install pnpm

```powershell
npx get-pnpm
pnpm --version
```

The project pins pnpm `12.3.4` in `package.json`.

## 3. Clone the GitHub repository

```powershell
cd C:\ruta\donde\guardas\proyectos
git clone https://github.com/EstuardoCif/Pilot-Automation.git
cd Pilot-Automation
```

Copy the contents of the provided project ZIP into this cloned folder, keeping the `.git` directory from the clone.

## 4. Install dependencies

```powershell
pnpm install
```

This creates `pnpm-lock.yaml`. Commit that lockfile.

## 5. Install Playwright browsers

All configured browsers:

```powershell

```

For only the Chromium pilot path:

```powershell
pnpm exec playwright install chromium
```

## 10. Configure Claude Code GitHub integration — subscription OAuth only

This project does **not** use an Anthropic Console credential. GitHub Actions authenticates Claude through a long-lived OAuth token generated by Claude Code from your Claude subscription.

Authenticate GitHub CLI:

```powershell
gh auth login
```

From the repository root, start Claude Code:

```powershell
claude
```

Inside Claude Code run:

```text
/install-github-app
```

Authorize/install the Claude GitHub App for this repository. If Claude offers to generate a default workflow, choose **Skip for now** because this repository already includes its own Claude workflows.

Exit Claude Code and return to normal PowerShell. Generate the CI OAuth token:

```powershell
claude setup-token
```

Complete the browser authorization if prompted. Claude Code prints the token in the terminal and does not save that generated token for you, so copy it immediately and keep it private.

Now go to:

`GitHub repository -> Settings -> Secrets and variables -> Actions -> New repository secret`

Create exactly:

```text
Name: CLAUDE_CODE_OAUTH_TOKEN
Value: <paste the token generated by claude setup-token>
```

Do not put this token in `.env`, workflow YAML, README, source code, a PR, an issue, a screenshot, or chat.

Both Claude workflows in this repository are already configured with:

```yaml
claude_code_oauth_token: ${{ secrets.CLAUDE_CODE_OAUTH_TOKEN }}
```

## 11. Test the automatic flow

Create a feature branch, make a small change, push it, and open a PR.
Expected flow:

1. `Playwright CI` runs independently.
2. `Claude Auto PR Review & Fix` reviews the PR using `CLAUDE_CODE_OAUTH_TOKEN`.
3. Claude reads `CLAUDE.md` and the PR quality-gate skill.
4. If a safe fix is required, Claude changes the PR branch.
5. Claude runs `pnpm typecheck` and `pnpm test:smoke`.
6. If validation succeeds, Claude commits and pushes the fix.
7. Claude's own push does not recursively start another Claude run.
8. The normal Playwright CI runs again against the new commit.

## 12. Recommended GitHub protection

After the first successful PR run, protect `main` in GitHub:

- require a pull request before merging;
- require the `Chromium smoke + reports` status check;
- prevent direct pushes to `main`;
- keep Claude's write access limited to PR branches;
- keep a human approval/merge step.

This makes Claude an automated reviewer/fixer, not an automatic merger.
